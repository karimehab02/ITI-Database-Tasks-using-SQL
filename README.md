# ITI-Database-Tasks-using-SQL
# 📊 SQL Queries Practice

This repository contains a collection of **SQL queries** that demonstrate the most common and essential SQL statements used in real-world database operations.

---

## 📌 Topics Covered

1. **SELECT** – Retrieve specific columns or all data from a table.
2. **FROM** – Specify the table(s) where the data comes from.
3. **WHERE** – Filter records based on conditions.
4. **ORDER BY** – Sort results in ascending or descending order.
5. **GROUP BY** – Group rows that have the same values in specified columns.
6. **HAVING** – Apply conditions on grouped records.
7. **Subqueries** – Use a query inside another query.
8. **JOINs** – Combine rows from two or more tables.
